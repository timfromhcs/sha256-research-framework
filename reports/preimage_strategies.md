# Search Strategy Comparison

Generated by `tools/measure_scaling.py`. Every value below was measured on
the machine described under *Environment* by an actual run. Nothing is
extrapolated.

## Scope and honesty statement

> Full 64-round SHA-256 preimage resistance is 2^256 compression-function
> evaluations, approximately 1.16e77. That is not reachable by any
> engineering means; it is a physical bound. This campaign measures where
> a *direct* SAT encoding of the compression function stops closing, which
> is a different and much weaker question.
>
> No full SHA-256 preimage and no full SHA-256 collision is claimed here.
> Every positive result below was re-checked by the segregated
> `sha-verifier` engine before being recorded as verified.

## Findings

- **Deepest independently verified preimage: 18 rounds**
  (classification `ReducedRoundPreimage`, confirmed by `sha-verifier`).
- **First unresolved round: 18** (outcomes: TIMEOUT).
  The solver returned no verdict within its budget. This is *not* a proof
  that no preimage exists at 18 rounds, and a `UNSAT` label from the
  solver means only that this encoding found no model within the budget.
  Treat it as a statement about this encoding and this budget.

## Strategy comparison

All rows target the same round count and encoding; only the search
strategy differs. Negative results are included deliberately.

| Strategy | CNF vars | Solve (s) | Found at | Outcome |
|:---------|---------:|----------:|----------:|:--------|
| unrestricted | 16725 | 13.22 | - | VERIFIED |
| pin W[0..3] | 16725 | 285.53 | - | TIMEOUT |
| pin W[0..7] | 16725 | 285.22 | - | TIMEOUT |
| Dobbertin E@12, 24 bits | 16725 | 115.65 | - | VERIFIED |
| cube-and-conquer (12 bits) | 16725 | 287.02 | cube 16/4096 | VERIFIED |

Message-word pinning, Dobbertin state constraints and
Cube-and-Conquer all made the instance *harder* here. A one-block
preimage is overdetermined by 2^256, so removing free variables
removes the solver's room to manoeuvre without making propagation
easier. See
[`docs/research/advanced-strategies.md`](../docs/research/advanced-strategies.md).
